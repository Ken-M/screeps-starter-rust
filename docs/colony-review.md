## 4. 現在の設計（体制刷新後）

### 判断のレイヤー
- **ロール**: miner（source 固定・WORK5上限）/ hauler（CARRY:MOVE 1:1）/ worker（建設→修理→アップグレード、duty 1体+RCL3未満は半数がアップグレード傾斜）/ defender（敵検知時のみ、MOVE前置+ATTACK）
- **目標**: creep 総数比ではなくコロニー構造の関数（source数・敵の有無・施設）。人口上限=目標合計
- **先行生産**: miner の残寿命 250 tick で後継を生産、同じ source を引き継ぐ
- **緊急モード**: 人口<4 または miner/hauler がゼロ → 今あるエネルギーで即時生産
- **防衛**: セーフモードは「重要建造物HPの実減少×武装敵」のANDでのみ。タワーは実効ダメージ+ヒーラー優先
- **建設**: 20tickごとに RCL 上限との差分を自動配置（container=source脇、拠点=市松、道路=沼のみ）

### 手段のレイヤー
- tick キャッシュ（建造物・敵・地形・仕事サマリ・コロニー観測）、静的/動的コスト層、move_by_path、Memory キーは `mem::keys` に集約
- util は cache / pathing / predicates / stats / finders の5モジュール
- 純粋関数テスト11件（role_targets / build_body / tower減衰 / danger_cost）

## 5. 刷新時に発生し修正した回帰（教訓）

| 回帰 | 症状 | 原因と修正 |
|---|---|---|
| ロスター化前の重複読み | creeps 4.5→7.4 CPU | body/Memory を tick 内で複数回読み直し → 1回読みのロスター化 |
| スタック過敏判定 | CPU倍増 | 正常渋滞を誤検知し毎tickフル再探索 → 閾値5+カウンタリセット（後に退役で機構ごと削除） |
| upgrade係が粘着しない | downgrade進行 | 「毎tick先頭のworker」指名が移ろい誰も到着しない → Memoryフラグで固定 |
| **worker のエネルギー欠落** | 全workerが立ち尽くす | 退役時に採取フェーズの代替を用意し忘れ → hauler の調達ロジックを共有化 |
| **hauler 全滅デッドロック** | 人口11→4、生産停止 | hauler ゼロ→補給されず実質上限300 < hauler 設計コスト400 → 緊急モードで即時生産 |

いずれもログ常駐+コンソール照会の観測基盤が実測で捕捉した。**「デプロイ後 N tick の自動ベンチ比較」をスクリプト化すれば検知が人手不要になる**（未実装・推奨）。

## 6. 防衛評価 — 「攻撃を受けた時に生産と防御は間に合うか」

**結論: 現時点では大規模攻撃には間に合わない。小規模には概ね対処可能。ただし今は無敵時間中。**

### 時間割
| 期間 | 状態 |
|---|---|
| 現在〜+約14,000 tick | **無敵**（誤発動セーフモードの残り効果） |
| その後 約30,000 tick | **セーフモード発動不能**（クールダウン。在庫1はあるが使えない）|
| それ以降 | 在庫1を実害検知で発動可能 |

### 応答チェーンの実測値（容量450時点）
- 検知: 敵入室と同tick（ColonyState.hostiles_present）
- defender 生産: body 3×MOVE+3×ATTACK=390エネルギー、18 tick（+エネルギー貯蓄待ち 0〜40 tick）
- 移動: 10〜40 tick
- **合計 40〜100 tick**。攻撃力は 90/tick

### 脅威別の見立て
- **NPCインベーダー級（1〜2体）**: defender×2 + 危険域回避コストで概ね対処可能
- **本気のプレイヤー（ATTACK10以上/ヒーラー付き）**: 応答前に miner（3tickで撃破される）と経済が壊滅。**タワーなしでは守り切れない**
- 最後の砦はセーフモード自動発動（spawn等の被弾で即時）だが、上記の空白30,000 tickの間は使えない

### 提言（優先順）
1. **無敵時間中に RCL 3 へ全振り**し、タワー＋充填まで到達する。タワーは応答0tick・威力600で、防衛の質が根本的に変わる（自動配置は実装済み。到達すれば自動で建つ）
2. defender 数を敵の攻撃パーツ数に比例させる（現在は固定2）
3. 敵入室時に非戦闘 creep を spawn 周辺へ退避させる（現在は danger コストによる経路回避のみ）
4. 中期: spawn を守る最小限の rampart をプランナーに追加
